🚀 30 Days Quantum Challenge

From Quantum Fundamentals to Hybrid Quantum AI

A 30-day hands-on quantum computing journey documenting my learning, projects, and practical implementations using Python, Qiskit, PennyLane, IBM Quantum, and Machine Learning. This repository showcases four major projects that progressively build expertise in quantum algorithms, secure communication, quantum cryptography, and hybrid quantum machine learning.

📖 About

This challenge was designed to strengthen my understanding of Quantum Computing through project-based learning.

Rather than only studying theory, I developed complete applications demonstrating real-world quantum technologies.

🤖 Final Capstone — Hybrid Quantum Image Classifier
Project Overview

A Hybrid Quantum-Classical Machine Learning system for environmental scene classification using classical deep learning for feature extraction and a Variational Quantum Circuit for classification.

Problem Statement

Develop an efficient image classification model that combines the strengths of deep learning with quantum machine learning to classify environmental scenes such as roads, skies, and water.
